# UI/UX v2｜極簡四頁＋獨立流程頁（#70）
四個日常操作頁：總覽、AI 決策、交易、設定；另設流程頁作為 n8n 式診斷入口。手機底部、桌面上方五項導航，一次顯示一頁。固定顯示 PAPER/OFF、資料及服務狀態，缺值用 —，不偽造資產、收益、決策或成交。模型/API/風控及啟停屬後端權威，未接線控制 disabled。進階量化、日誌與診斷折疊。

## 流程頁
市場與時事雙來源 → 事件觸發 → AI 決策 → 量化驗證 → 獨立風控 → 紙上執行 → 帳務稽核。節點可點選查看職責、狀態、阻塞原因；預設 8 節點未接線。離線示範僅真正執行 risk fixture，其餘未接線或阻塞，不假裝全鏈路執行。明確區分系統架構與示範結果，正常/過期/風險/停機情境，回到架構清除示範狀態。

M3 後續由權威服務供應 runId、nodeId、依賴、事件時間、開始/結束、耗時、attempt、狀態（pending/running/succeeded/rejected/failed/blocked/skipped/offline）、錯誤碼、原因、來源及證據引用。顯示目前執行進度、根因與下游阻塞、歷史 run、最後成功時間與資料新鮮度；多分支及 HOLD/拒絕不得誤判成故障。不記錄秘密、原始私密提示或交易金鑰。初期唯讀診斷，不允許拖曳改接、重跑下單或繞過風控。後端未接線時時間顯示 —；不得使用虛構耗時或完成率。

## 驗收
320/390/1440px E2E，五頁導覽、深連結、返回/重新整理、唯一可見頁、未接線控制禁用、模式不變、無橫向溢位、四情境風控。流程初始全部 off、節點可選、示範正常保護拒絕定位於獨立風控（與系統故障區分）、下游 blocked、復原後清除。後續需真機、可及性、真實 run 資料及故障注入驗收。

## Android APK 特化（沉浸式全螢幕）
Android 原生 MainActivity 預設隱藏狀態列與導覽列，邊緣滑動可暫時喚回；視窗恢復焦點重新進入沉浸模式。不攔截 Android 返回、Home 或系統手勢，不強制常亮或鎖定方向。原生 content root 使用 WindowInsetsCompat 的穩定系統列、display cutout、mandatory gestures 計算四邊安全距離；隱藏系統列仍保留必要邊距，避免短暫喚回時遮住 UI。WebView 保留 IME inset；前端不自行猜測手機狀態列高度。Web/Windows 不啟用沉浸模式。
驗收：POCO F8 Ultra / Android 16，直向及橫向、手勢及三鍵導覽、喚回系統列、切換背景/前景、旋轉、鍵盤、五頁底部導航及流程節點均不遮擋；真機截圖及操作結果必須另存。CI 可驗證 Kotlin 編譯與打包，不能替代上述實機驗收。
