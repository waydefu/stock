# UI/UX v2｜極簡四頁＋獨立流程頁（#70）
四個日常操作頁：總覽、AI 決策、交易、設定；另設流程頁作為 n8n 式診斷入口。手機底部、桌面上方五項導航，一次顯示一頁。固定顯示 PAPER/OFF、資料及服務狀態，缺值用 —，不偽造資產、收益、決策或成交。模型/API/風控及啟停屬後端權威，未接線控制 disabled。進階量化、日誌與診斷折疊。

## 流程頁
市場與時事雙來源 → 事件觸發 → AI 決策 → 量化驗證 → 獨立風控 → 紙上執行 → 帳務稽核。節點可點選查看職責、狀態、阻塞原因；預設 8 節點未接線。離線示範僅真正執行 risk fixture，其餘未接線或阻塞，不假裝全鏈路執行。明確區分系統架構與示範結果，正常/過期/風險/停機情境，回到架構清除示範狀態。

M3 後續由權威服務供應 runId、nodeId、依賴、事件時間、開始/結束、耗時、attempt、狀態（pending/running/succeeded/failed/blocked/skipped/offline）、錯誤碼、原因、來源及證據引用。顯示目前執行進度、根因與下游阻塞、歷史 run、最後成功時間與資料新鮮度；多分支及 HOLD/拒絕不得誤判成故障。不記錄秘密、原始私密提示或交易金鑰。初期唯讀診斷，不允許拖曳改接、重跑下單或繞過風控。後端未接線時時間顯示 —；不得使用虛構耗時或完成率。

## 驗收
320/390/1440px E2E，五頁導覽、深連結、返回/重新整理、唯一可見頁、未接線控制禁用、模式不變、無橫向溢位、四情境風控。流程初始全部 off、節點可選、示範失敗定位於獨立風控、下游 blocked、復原後清除。後續需真機、可及性、真實 run 資料及故障注入驗收。
